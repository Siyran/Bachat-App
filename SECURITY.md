# Security Policy

## Supported Versions

Only the latest release and the current `main` branch are actively maintained with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Bachat, please report it responsibly:

1. **Do not create a public issue** on GitHub.
2. Email your findings directly to **abrar.ahmad@iust.ac.in**.
3. Please include:
   - Description of the vulnerability and its potential impact.
   - Detailed step-by-step reproduction steps or proof-of-concept.
   - Any suggested mitigations or patches.

### Response Timeline
- You will receive an initial response acknowledging receipt within 48 hours.
- Maintainers will verify the issue and keep you informed of progress.
- Once a fix is validated and released, we will coordinate public disclosure.
